# pathfinder_run_movement (Action)

Runs the movement plan that is stored on the device, such as one uploaded by `pathfinder_movement_plan`. The device moves while the action runs.

Actions require Terraform 1.14 or later. The action returns once the device has finished moving, or fails after 15 minutes.

## Example Usage

```terraform
# Runs the plan that is stored on the device, such as one uploaded by pathfinder_movement_plan.
action "pathfinder_run_movement" "example" {}
```

To run the action without changing any resource, use:

```shell
terraform apply -invoke=action.pathfinder_run_movement.example
```

To run it after a `pathfinder_movement_plan` is created, see the example in the [`pathfinder_movement_plan` documentation](../resources/movement_plan.md).
