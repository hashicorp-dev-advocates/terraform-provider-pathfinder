# pathfinder_movement_plan (Resource)

Uploads a movement plan to the device without running it. Use the pathfinder_run_movement action to run the plan. The device keeps a single plan in memory, so it is lost when the device restarts and only one pathfinder_movement_plan resource should exist per device.

## Example Usage

```terraform
# Uploads the plan to the device. The device does not move.
resource "pathfinder_movement_plan" "example" {
  name = "example"

  steps {
    angle     = 0
    direction = "forward"
    distance  = 1
  }

  steps {
    angle     = 90
    direction = "forward"
    distance  = 1
  }

  # Run the plan once it has been uploaded.
  lifecycle {
    action_trigger {
      events  = [after_create]
      actions = [action.pathfinder_run_movement.example]
    }
  }
}

# Runs the plan that is stored on the device.
action "pathfinder_run_movement" "example" {}
```

### Running the plan

The `pathfinder_run_movement` action runs the plan that is stored on the device, and returns once the device has finished moving. It requires Terraform 1.14 or later.

The `action_trigger` in the example runs the plan after the resource is created. To run the stored plan again, without changing the resource, use:

```shell
terraform apply -invoke=action.pathfinder_run_movement.example
```

### Device restarts

The device keeps the plan in memory only. After a restart, the next plan finds the plan missing and creates the resource again, which also fires the `after_create` trigger: the device moves through the plan again on that apply. If the device must not move after a restart, leave out the `action_trigger` and invoke the action by hand instead.

### Nested Schema for `steps`

Required:

- `angle` (Number) Angle to turn the device before moving, in degrees. `0` keeps the heading, up to `180` turns right, and above `180` turns left.
- `direction` (String) Direction to move the device in.
- `distance` (Number) Distance to move the device, as a whole number. It has no fixed unit: the device drives its motors with PWM, so the distance covered depends on the device and the surface.
